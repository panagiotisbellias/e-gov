# ADR-0006: Versioning Strategy

## Status
Accepted

## Decision
Use Semantic Versioning
```
MAJOR.MINOR.PATCH
```

Example:
- v2.0.0 – Community & Quality
- v2.1.0 – Release Infrastructure
- v2.0.1 – Maintenance (Dependabot)

## Why
- Clear expectations for contributors
- Professional release structure
- Aligns with open-source standards
